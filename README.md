# Marina Domingos | Saúde Predial

Versão estática do site institucional da arquiteta e urbanista Marina Domingos
Fernandes, pronta para publicação no GitHub Pages.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `marina-domingos`.
2. Envie **todo o conteúdo desta pasta**, preservando a estrutura de diretórios.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.
6. Aguarde o endereço de publicação aparecer na mesma tela.

O projeto não requer instalação, compilação ou servidor. O arquivo `index.html`
é a página inicial e os caminhos relativos permitem que o site funcione tanto em
um repositório comum quanto em domínio próprio.

## Estrutura principal

- `index.html`: página institucional e porta de entrada para os serviços;
- `vistoria-imovel-novo-recife/`: página do serviço de recebimento;
- `vistoria-pre-compra-recife/`: página do serviço para imóvel usado;
- `vistoria-locacao-recife/`: página do serviço de entrada ou saída;
- `laudos-patologia-construcoes-recife/`: página de laudos e manifestações;
- `casos-reais/`: sínteses anonimizadas da experiência profissional;
- `404.html`: página de erro personalizada;
- `assets/css/styles.css`: identidade visual e responsividade;
- `assets/css/pages.css`: componentes das páginas internas e casos;
- `assets/js/main.js`: animações progressivas e eventos de clique;
- `assets/images/`: fotografias e logomarca otimizadas;
- `favicon.png` e `favicon.svg`: ícones do navegador;
- `robots.txt`: orientação para mecanismos de busca;
- `sitemap.xml`: mapa do site enviado aos mecanismos de busca;
- `.nojekyll`: impede o processamento desnecessário pelo Jekyll.

## Domínio próprio

O domínio `marinadomingos.com.br` está configurado nas opções do GitHub Pages.
O arquivo `CNAME` na raiz deve permanecer contendo apenas:

```text
marinadomingos.com.br
```

As URLs canônicas, as tags sociais, o `robots.txt` e o `sitemap.xml` utilizam o
domínio próprio.
